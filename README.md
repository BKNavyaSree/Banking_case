# Banking Analysis Dashboard

An interactive banking data analysis project using **Python, Pandas, and Microsoft Power BI** to explore customer profiles, loans, deposits, account balances, and customer engagement.

## 📌 Project Overview

The Banking Analysis project focuses on analyzing banking customer data to identify financial patterns and generate meaningful business insights. Python is used for Exploratory Data Analysis (EDA), while Power BI is used to create interactive dashboards for visualizing key banking metrics.

## 🎯 Objectives

- Analyze customer demographic and financial information.
- Understand loan and deposit patterns.
- Explore customer income, age, and account balances.
- Identify relationships between different banking attributes.
- Develop interactive dashboards using Power BI.
- Support data-driven banking decisions through visualization.

🚀 How to Run the Project

3. Open the .pbix dashboard file.
4. Update the dataset path if required.
5. Refresh the data.
6. Explore the interactive dashboard.
Python EDA
1. Install Python or open Google Colab.
2. Open either EDA Jupyter Notebook.
3. Upload the required CSV dataset.
4. Install the necessary libraries:
